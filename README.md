# ₹5,00,000 Investment Portfolio Simulation

A practical equity portfolio simulation project built to understand portfolio construction, sector allocation, risk management, and benchmark comparison using Indian equities.

## Project Overview

- Initial Corpus: ₹5,00,000
- Period: Jan 2023 – Dec 2024
- Benchmark: Nifty 50
- Strategy: Growth + Value Blend
- Portfolio: 15 Stocks across 8 sectors

## Key Metrics

- Portfolio CAGR: 16.8%
- Nifty CAGR: 12.4%
- Alpha Generated: +4.4%
- Max Drawdown: −8.2%
- Sharpe Ratio: 0.92

## Tools Used

- Microsoft Excel
- PowerPoint
- NSE/BSE Data
- Moneycontrol
- Screener.in

## Key Learnings

- Diversification reduced portfolio volatility
- Rebalancing improved portfolio discipline
- Defensive allocation helped reduce drawdowns
- Momentum + value blend outperformed benchmark
